# Support

## Questions about a repository

Open a **Discussion** if the repo has them enabled, otherwise an **Issue** with the `question`
label. Please search existing issues first.

Include what you tried, what you expected, what happened instead, and your versions. A question with
that context usually gets a useful answer on the first reply.

## Bugs and feature requests

Use the issue templates. They ask for the things I would otherwise have to ask you for.

## What is not supported here

These are personal and consultancy repositories, maintained around client work. I read everything,
but I cannot promise a response time, and some repos are archived experiments rather than
maintained software. Check the last commit date before depending on one.
